zMapUnlocker — handoff / текущий статус
========================================

ЦЕЛЬ
Для Gothic II Addon: при открытой карте (текстура карты + GPS-маячок ГГ, если доступен)
разрешить горизонтальное вращение мышью и движение персонажа. Затем проверить,
обновляется ли GPS-маячок в реальном времени; если нет — найти механизм его обновления.

РАБОЧИЕ ОГРАНИЧЕНИЯ
- Рабочая ветка: feature/zMapUnlocker-map-live-marker
- Менять только Plugin_G2A.cpp.
- Проверять только workflow .github/workflows/buildG2A.yml (G2A).
- main не сливать без прямой просьбы.
- Не тратить сообщения на согласование: один ответственный набор изменений за итерацию.
  Объём и состав изменений выбирает агент. После коммита — короткий отчёт и конкретный
  сценарий игрового теста. Пользователь собирает/тестирует и сообщает результат.
- Не повторять инструкции по сборке в каждом цикле. Если нужен лог, пользователь кладёт
  его в Temp на main; агент читает его оттуда.
- В инструкциях указывать только действия, необходимые для текущего теста.

ИСТОРИЯ ИССЛЕДОВАНИЯ
1. Исходная идея: перехватывать обработку событий карты, не блокировать Escape,
   не вызывать принудительно UpdatePosition, сначала наблюдать за штатным GPS-маячком.
2. Первая попытка пропускала события из oCDocumentManager::HandleEvent и собирала
   диагностику мыши/клавиш/состояния callback. Плагин загружался, но управление не
   разблокировалось.
3. Следующая диагностическая версия добавила хуки:
   - oCViewDocumentMap::UpdatePosition (G2A: 0x0068D7B0)
   - деструктор oCViewDocumentMap (0x0068D470)
   - oCDocumentManager::Show (0x0065F300)
   - oCDocumentManager::HandleEvent (0x0065F450)
   И опрос UI/ввода из Game_Loop.
4. Пользователь сообщил: при открытии карты игра вылетает, zMapUnlocker.log не создаётся.
   Temp/Crash.txt содержит только UNHANDLED EXCEPTION и CALLSTACK:
   0023:0135F470 (0x00000000 0x00000000 0x00000000 0x00000000) <UNKNOWN>.
   Это не указывает точную функцию, но вылет появился в версии с несколькими хуками.
5. Текущий диагностический шаг: все экспериментальные хуки и обращения к UI удалены
   из Plugin_G2A.cpp. Коммит ed38910456786568b3442283acf742ef02c70f43.
   Цель теста — проверить, исчезает ли вылет. Если да, возвращать хуки по одному,
   начиная с UpdatePosition, с безопасными маркерами входа/выхода.

ВАЖНЫЕ СИГНАТУРЫ SDK (Gothic II Addon)
- oCDocumentManager::Show(int): 0x0065F300
- oCDocumentManager::GetDocumentView(int): 0x0065F3D0
- oCDocumentManager::HandleEvent(int): 0x0065F450
- oCViewDocumentMap::UpdatePosition(): 0x0068D7B0
- oCViewDocumentMap::~oCViewDocumentMap(): 0x0068D470
- oCViewDocumentMap содержит ViewArrow и ViewPageMap; класс наследует oCViewDocument.
- zCInput имеет SetDeviceEnabled/GetDeviceEnabled, GetState, KeyPressed.
- zCInputCallback имеет SetEnableHandleEvent/GetEnableHandleEvent/DoEvents.
- В SDK UpdatePosition объявлен именно в oCViewDocumentMap, не как метод базового zCView.
  При новых хуках соблюдать фактический тип класса и ABI.

ТЕКУЩИЙ ТЕСТ
1. Собрать DLL из ветки feature/zMapUnlocker-map-live-marker.
2. Запустить игру, загрузить сохранение, открыть карту.
3. Проверить, вылетает ли игра при открытии карты. Если карта открылась — оставить её
   на экране 10 секунд, затем закрыть Escape.
4. Сообщить результат. Лог на этом этапе не нужен: диагностическое логирование отключено.
